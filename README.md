# WordPress com Docker

Dois trabalhos no mesmo repositório, cada um em sua pasta:

- [Trabalho 1](trabalho-1/README.md): WordPress e MySQL com Docker Compose.
- [Trabalho 2](trabalho-2/README.md): três instâncias WordPress, MySQL e Nginx com balanceamento de carga.

As senhas nos arquivos Compose são valores de demonstração para uso local. Não exponha estas aplicações à Internet sem trocar as credenciais e atualizar as imagens antigas exigidas pelo enunciado.

Os dois ambientes usam bancos independentes. Execute-os separadamente para facilitar a coleta das evidências.
